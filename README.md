# 长期卡对账台（lifetime-ledger）

「终身卡 / 年卡 / 储值卡」这类一次付清、之后每次不再单独掏钱的卡，到底值不值？

答案不是「总价 ÷ 单次价」。三件事会改变它：

1. **你会越去越少**（新鲜感、搬家、换工作）——年到访衰减率
2. **店可能会先没了**——年消失概率
3. **先掏出去的钱本来能生息**——年折现率

本页把这三件事和到访频率一起摊成逐年一本账，给出：

- **两种付法的现值对照**：全程按次付 vs 买卡（余额/期限不够时自己补上），差额就是结论
- **盈亏平衡频率**：第 1 年每月至少去几次才划算
- **回本时点**：折扣累计追平卡价要多少次、第几年
- **等效年费**：卡面年费 / 摊到「卡还有效的年数」/ 摊到次数，三个口径都算出来
- **储值卡的赠送与残留**：赠送率、按面值折扣、面值哪天用尽、期末还剩多少没用完
- 逐年表格、口径对照、要点、卡清单对照、15 行敏感性、结构自检、CSV / Markdown / JSON / 1080×1350 结果卡 PNG

## 口径（可复算）

第 t 年（t = 0, 1, 2, …）：

| 量 | 公式 |
|---|---|
| 存活概率 | `S_t = (1 − m)^t`，m = 年消失概率 |
| 当年到访次数 | `n_t = f × (1 − d)^t`，f = 第 1 年到访次数/年，d = 年到访衰减率 |
| 期望到访 | `E_t = n_t · S_t`（只乘一次存活） |
| 当年折扣 | `D_t = E_t × A`，A = 不用卡时的单次价 |
| 折现因子 | `v_t = 1 / (1 + r)^t` |
| 省下的现值 | `costNoCard − costWithCard`，其中 `costWithCard = P + Σ S_t·自付_t·v_t` |
| 回本所需次数 | `P ÷ A`（与衰减、消失、折现都无关） |
| 盈亏平衡频率 | 使「折扣累计 = P」的 f，二分求解 |

储值卡额外用**泊松到达下的期望封顶消费**：`E[min(K·A, 余额)]`，K ~ 泊松(λ)。
直接写 `min(λ·A, 余额)` 是错的（Jensen 不等式，本轮实测差 2.5%）。

## 边界

本页只算钱，不给消费建议；衰减率、消失概率、折现率全由用户自填，不联网、不查任何行业倒闭率、
不预测任何商家的经营状况；不处理卡面条款、退卡转让、共享卡、叠加优惠、分期与税费。
默认样例与 8 个内置场景**都是虚构示例**。详见页面「这份账不算什么」一节。
